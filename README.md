# Plugins da Divos da IA

Catálogo de plugins do Claude Code publicados pela Divos da IA.

## Instalar

No Claude Code, rode:

```text
/plugin marketplace add DivosdaIA/claude-plugins
```

Depois instale o plugin que quiser:

```text
/plugin install go-viral-diva@divos-da-ia
```

## Plugins

| Plugin | O que faz |
|---|---|
| [GoViralDiva](https://github.com/DivosdaIA/go-viral-diva) | Pautas, ângulos, roteiros e legendas virais em português. Beta em outubro de 2026. |

## Atualizar

```text
/plugin marketplace update divos-da-ia
```
